# Contributing

Thanks for your interest in contributing to Algorithmic Morphology.

## Workflow

1. Fork the repository and create a branch from `main`.
2. Make a focused change and commit it with a clear message.
3. Open a pull request against `main` and explain the motivation and the change.
4. Include any checks you ran. If the change introduces a new check, document how to run it.

For substantial changes, open an issue first so the approach can be discussed. Please keep discussions constructive and focused on the work.
